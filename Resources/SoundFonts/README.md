# SoundFonts

Every `.sf2` file in this folder is bundled with the app. A file named `GeneralUser…` or `GM…` is used for the Sketchpad's wider palette of sounds; the first other file (by name) is the piano.
The files are large and not kept in git. Fetch both with:

```sh
Scripts/fetch-soundfonts.sh
```

Without a SoundFont here the app uses the General MIDI sounds built into macOS.
